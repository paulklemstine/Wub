Connecting to Wub Backend

This web page can stream directly from your running Python server:

  • Local LAN Direct (Recommended): Open http://192.168.1.136:8123 directly in your browser. (The backend server serves this entire UI natively without mixed-content restrictions).
  • Cloudflare Tunnel (HTTPS/WSS): Run cloudflared tunnel --url http://127.0.0.1:8123 on the host machine and paste the resulting https://...trycloudflare.com URL into the Server box. Works over GitHub Pages without browser warnings!
  • GitHub Pages + Insecure Content: If connecting to http://192.168.1.136:8123 from https://paulklemstine.github.io/Wub/, your browser will block mixed content by default. In Chrome/Edge: click the icon next to the URL in the address bar → Site Settings → set Insecure content to Allow.
